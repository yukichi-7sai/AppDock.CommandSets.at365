# AppDock コマンドセット

Windows版AppDockで使えるショートカットの配布一覧です。AppDockの「コマンドセット」を開き、「一覧を更新」で配布中のセットを表示します。セットを選ぶと、取り込む前に操作名と送信キーを確認できます。

「取り込む」を押し、「コマンドセンターで開く」からキーやジェスチャーを割り当ててください。更新日は各セットの内容が最後に変わった日です。「再取り込み」で配布内容を復元できます。アンインストール後も、同じIDのコマンドを取り込み直せば以前の割り当てを使えます。

セットの追加や修正は、`sets/` のJSONを対象にしたプルリクエストを受け付けています。既存の操作はセットIDとコマンドIDを保ってください。
